Peakfront brand logos and favicons

Source SVGs:
  logo.svg         — full wordmark (dark text, light backgrounds)
  logo-light.svg   — full wordmark (light text, dark backgrounds)
  logo-mark.svg    — shield mark only
  favicon.svg      — favicon source (same mark as logo-mark.svg)

Generated PNG / ICO (run after editing SVGs):
  npm run generate:logos
  npm run generate:favicons

All site and document references use /logo/... paths.
