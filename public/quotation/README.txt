Peakfront Quotation Template
============================

Editable files:

1. Word template (recommended for client-facing quotes)
   public/quotation/Peakfront-Quotation-Template.docx
   Open in Microsoft Word. Edit text, line items and totals.

2. Excel template
   public/quotation/Peakfront-Quotation-Template.xlsx
   Open in Microsoft Excel, Google Sheets or LibreOffice Calc.
   Edit client details, line items, rates and totals auto-calculate.

2. Online editor (browser)
   Open /quotation or public/quotation/index.html
   Fill in fields, add/remove rows, then Print → Save as PDF.

Regenerate Excel template:
  npm run generate:quotation

Notes:
  - VAT is set to 5% (UAE standard).
  - Update quote number, TRN and terms as needed before sending to clients.
