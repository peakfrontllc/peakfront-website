Peakfront Request For Quotation (RFQ) Template
===============================================

Use this when requesting quotes from suppliers and vendors.

Editable files:

1. Word template
   public/docs/rfq/Peakfront-RFQ-Template.docx

2. Excel template
   public/docs/rfq/Peakfront-RFQ-Template.xlsx

3. Online editor (browser)
   Open /docs/rfq or use the Official Documents hub at /docs

Regenerate templates:
  npm run generate:docs

Notes:
  - RFQ number format: PFRQ-YYYY-NNN (e.g. PFRQ-2026-001).
  - You fill description, qty, unit and specifications; supplier fills unit price and lead time.
